Frequently asked questions

Can I buy ebooks on this demo website right now?

This is a working storefront preview, but payments and real downloads are not connected yet. Do not accept payments until checkout and file delivery are configured and tested.

How do I add my own ebooks?

Use “Sell an ebook” to preview the product submission flow. For a live store, connect a backend or ecommerce platform, upload your PDF privately, and configure order records and secure delivery.

How can I accept payments in India?

Choose a supported payment provider such as Razorpay or Cashfree, complete its merchant onboarding, and connect checkout using its official integration. Never put secret API keys in browser code.

Will buyers receive the PDF automatically?

Not in this static starter. Automated delivery needs a server-side order verification step and private file storage or expiring download links.
